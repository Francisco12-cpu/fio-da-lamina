# Fio da Lâmina

Protótipo de combate com espada em 3D (Three.js), inspirado na sensação de combate de
*Ghost of Tsushima* (sem copiar nada proprietário).

**🎮 Jogar:** https://francisco12-cpu.github.io/fio-da-lamina/

## Rodar localmente

Windows: dê **duplo clique em `iniciar.bat`** — ele instala o necessário, abre o jogo no PC e
mostra o endereço para abrir no celular (mesma rede Wi-Fi).

Ou pelo terminal:
```bash
npm install
npm run dev
```
